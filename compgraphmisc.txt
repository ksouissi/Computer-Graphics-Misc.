OM = [OM.w^v/(u.w^v)]*u + [OM.u^w/(v.u^w)]*v + [OM.v^u/(w.v^u)]*w
  = [OM.w^v/(w.v^u)]*u + [OM.u^w/(w.v^u)]*v + [OM.v^u/(w.v^u)]*w

Proj. texel (pixel) P, retro proj. pixel P (texel) T, OT = w.v^u/(OP.v^u)*OP = [OP.w^v/(OP.v^u) OP.u^w/(OP.v^u) 1][u v w]
No need for world-view transform (see below.)

OP[i j k] = [x y 1]    OT[i j k] = [x*z y*z z]
OT[u v w] = [(x*z*x[w^v]** + y*z*y[w^v] + z*z[w^v])/(w.v^u) (x*z*x[u^w] + y*z*y[u^w] + z*z[u^w])/(w.v^u) 1] (see *, above)
          = [z*(x*x[w^v] + y*y[w^v] + z[w^v])/(w.v^u) z*(x*x[u^w] + y*y[u^w] + z[u^w])/(w.v^u) 1]
1/z*u[OT] = x*x[w^v]/(w.v^u) + y*y[w^v]/(w.v^u) + z[w^v]/(w.v^u) = a*x + b*y + c where a = i.w^v/(u.w^v = w.v^u), b = j.w^v/(w.v^u)
1/z*v[OT] = x*x[u^w]/(w.v^u) + y*y[u^w]/(w.v^u) + z[u^w]/(w.v^u) = d*x + e*y + f, d = i.u^w/(w.v^u) and e = j.u^w/(w.v^u)

Hence, "u/z and v/z linear wrt. x, y" i.e., [1/z*(u|v)][(x, y) + (dx, dy)] = [1/z*(u|v)][x, y] + (a|d)*dx + (b|e)*dy
On the other hand, T on tex. plane [A B C -D]* that is A*x*z + B*y*z + C*z = D in other words, 1/z = x*A/D + y*B/D + C/D: 1/z is also linear wrt. x, y.
Thus lerp both (u|v)/z and 1/z, mul. by reciprocal of 1/z in order to retrieve (u|v)[x, y] 

* A = x[v^u] B = y[v^u] C = z[v^u] D = w.v^u
** x[X] means "x component of vec. X"

*** Persp. correct texture mapping with u, v at the vertices ***:

texture plane eq.: a*x + b*y + c*z - d = 0
xv = xs*zv, yv = ys*zv
a*xs*zv + b*ys*zv + c*zv = d
a*xs + b*ys + c = d/zv (d = 0: plane passes through origin i.e., eye, hence unseen as line on viewplane)

d != 0, A = a/d, B = b/d, C = c/d:
A*xs + B*ys + C = 1/zv (1/zv linear with respect to xs, ys)
u, v linear wrt. xv, yv, zv i.e., u = X*xv + Y*yv + Z*zv + W (e.g., u = Ux*xv + Uy*yv + Uz*zv + [-Px*Ux -Py*Uy -Pz*Uz], U vec. & P org. on plane)
u/zv = X*xs*zv/zv + Y*ys*zv/zv + Z*zv/zv + W/zv = X*xs + Y*ys + Z + W/zv = X*xs + Y*ys + Z + W*(A*xs + B*ys + C)
That is, u/zv = (X + W*A)*xs + (Y + W*B)*ys + (Z + W*C): u/zv (and likewise, v/zv) linear wrt. xs, ys)

*** Cross and Dot products ***:

Imagine 3 mutually orthogonal planes p, q, r. Let p ^ q ^ r  = O and x, y, z be 3 unit segments on resp. lines p ^ r, p ^ q and q ^ r making an oriented frame of reference. Further introduce 3 lines i, j, k with common point O such that k is orthogonal to plane s passing through both i and j. Suppose 3 directed segments of resp. i, j, k starting at O. Call u, v, w the vectors determined by these segments and A the (nonsigned) area of parallelogram (u, v). The problem is to get a possible value for w from u and v.
Project u and v on p, q and r. Since the frame is oriented, let Ap, Aq, Ar be the signed areas of the projections of (u,v) on p, q, r.
As can be seen, |Ap| = A*cos(angle(p, s)), |Aq| = A*cos(angle(q, s)) and |Ar| = A*cos(angle(r, s)) the angles being acute. Moreover, since k is orthogonal to s, angle(p, s) = angle(z, k), angle(r, s) = angle(y, k) and angle(q, s) = angle(x, k).
It follows that a possible value for w is (Aq, Ar, Ap). This w is of length A since the values of w's projections on x, y, z are equal to the signed areas of the projections of (u, v) on q, r, p resp.
The usual formula for cross product is a direct consequence.

Let i, j form an orthonormal frame and u = (x, y), v = (a, b) where |v| = 1. Call O the origin and V a line passing through O and oriented by v. Consider the projection of u on V along a line l perpendicular to V.
Algebraic length of proj. i on V along l = a, and alg. length of proj. j on V along l = b. Move l such that it passes through the point (x, 0) then through (0, y) until it lands on the extremity of u. By similar triangles, alg. length of proj. of seg. [O, (x, 0)] on V = x*a and alg. length of proj. of seg. [O, (0, y)] on V = y*b. It follows that the dot product of u and v is u.v = x*a + y*b.
Note that for real t, u.(t*v) = x*(t*a) + y*(t*b) = t*(u.v) (sim. triangles).

*** a^(b^c) = (a.c)*b-(a.b)*c ***

Let a, b and c be vectors in 3-space.

Suppose, without loss of generality, that |b| = |c| = 1 and a in plane(b, c).
Introduce d such that |d| = 1 and angle(b, d) = PI/2. Put x = a.b, y = a.d and a' = a^(b^c).

It follows that a' = y*sin(angle(b, c))*b - x*sin(angle(b, c))*d = -x*c + (y*sin(angle(b, c)) - (-x)*cos(angle(b, c)))*b = (a.c)*b-(a.b)*c,
since a.c = y*cos(PI/2-angle(b, c)) - (-x)*sin(PI/2-angle(b, c)) = y*sin(angle(b, c)) + x*cos(angle(b, c))

*** Polygon area A, centroid C ***:

x0 = xn, y0 = yn
A = 1/2*sum[i=0...n-1: (xi + xi+1)*(yi+1 - yi)]

(xi^3 - xi+1^3)*(yi+1 - yi)/(xi - xi+1) = (xi - xi+1)(xi^2 + xi+1^2 + xi*xi+1)*(yi+1 - yi)/(xi - xi+1) =>
C = (1/(6*A)*sum[i=0...n-1: (xi^2 + xi+1^2 + xi*xi+1)*(yi+1 - yi)], 1/(6*A)*sum[i=0...n-1: (yi^2 + yi+1^2 + yi*yi+1)*(xi - xi+1)])

let a polygon p be determined by points Pi, with edges PiP(i+1)%n, 0 <= i < n, call ui the vectors determined by these segments.

a(p) {	(* at least 3 points, |a(p)| = 2*area(p) and a(p) colinear with the normal to p *)
	b = 0
	u = u0
	i = 1
	do {
		b += u ^ ui
		u += ui
		i++
	} while (i < n-1)
	return b
}

*** World/View transform ***:
      i'   j'   k'
i    [1    0    0]
j    [0    1    0]
k    [0    0    1]
                                i'                                            j'                                k'
    i	[    sin(x) * sin(y) * sin(z) + cos(y) * cos(z)    sin(x) * sin(y) * cos(z) - cos(y) * sin(z)    cos(x) * sin(y)    ]
T = j	[                cos(x) * sin(z)                                cos(x) * cos(z)						-sin(x)			]
    k	[    sin(x) * cos(y) * sin(z) - sin(y) * cos(z)    sin(x) * cos(y) * cos(z) + sin(y) * sin(z)    cos(x) * cos(y)    ]

M[i' j' k'] = M[i j k] * T

Applying prosthaphaeretic rules:

cos(a) * cos(b) = (cos(a + b) + cos(a - b)) / 2
sin(a) * sin(b) = (cos(a - b) - cos(a + b)) / 2 (e.g., from cos(a + b) = cos(a) * cos(b) - sin(a) * sin(b))
sin(a) * cos(b) = (sin(a + b) + sin(a - b)) / 2 (sin(a + b) = sin(b) * cos(a) + cos(b) * sin(a))
